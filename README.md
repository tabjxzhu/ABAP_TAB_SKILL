# ABAP TAB Skill

A production-aware SAP ABAP development skill for requirement breakdown, technical design, code generation, code review, troubleshooting, and reusable knowledge extraction.

The skill focuses on practical ABAP judgment:

- Make assumptions explicit before generating code.
- Check production risks around data correctness, transaction boundaries, locks, authorizations, updates, and performance.
- Troubleshoot from evidence using SAP tools such as ST22, SM37, SM13, ST05, SAT, SQLM, SLG1, SU53, and related logs.
- Convert real engineering experience into reusable rules, prompts, checklists, and article patterns.
